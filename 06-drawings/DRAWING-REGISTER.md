# Drawing register

## Numbering

`MSL-<code>-DR-<nnn>`, for example `MSL-STR-DR-101`.

| Code | Discipline |
|---|---|
| GEN | General: site plan, masterplan |
| GEO | Geotechnics: ground model, retaining walls |
| HYD | Hydraulics: reservoir, dam, pipe network |
| STR | Structures: water tower, canopy |
| CIV | Civils: access road, earthworks |
| BRD | Brand: mask, posters, title block |

Revisions: P01, P02… while the drawing is in progress; C01 once it is final.
